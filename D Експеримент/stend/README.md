# ND-5 — мінімальний стенд

Стенд відтворює технічний прогін для дослідження політик керованої деградації за інферованої критичності сервісів.

## Запуск з нуля

```powershell
cd "D Експеримент\stend"
..\..\.venv\Scripts\python.exe -m pip install -r requirements.txt
..\..\.venv\Scripts\python.exe run_experiment.py
```

Після запуску в `out/` зʼявляться:

- `raw_runs__...csv` — усі окремі прогони;
- `summary__...csv` — середні значення та стандартні відхилення;
- `critical_loss__...png` — графік втрати критичної цінності.

## Що моделюється

- граф залежностей сервісів;
- справжня критичність і статично оголошений пріоритет;
- політики `fixed_declared`, `perfect_inference`, `inferred_independent`, `inferred_correlated`;
- навантаження, каскадна близькість, бюджет рішень і похибка інференції;
- пряма втрата від скидання та додаткова каскадна втрата.

Це технічний стенд для перевірки працездатності. Наукові діапазони факторів, метрика та baseline мають бути ратифіковані в A08 до наукового прогону.
