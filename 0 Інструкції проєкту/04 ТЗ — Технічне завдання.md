# 04 ТЗ — Технічне завдання

> **Що це.** Методологічний якір роботи. Заповнюється на **Фазі 0, до першого рядка
> контенту**. Після ратифікації керівником (**КТ-0**, див. [[08 Календар віх і контрольних точок]])
> стає незмінним: будь-яка зміна — нове `Р-N (к)` у [[LOG — Журнал рішень]].
>
> **Заповнюйте зверху вниз і не перескакуйте.** Кожен блок спирається на попередній.

---

## Блок 1. Ідентифікація

```
Тема (робоче формулювання):
Напрям (НД-N):
Рівень: бакалавр / магістр / PhD
Масштаб: Midi / Macro / Macro + ≈10 циклів
Здобувач:
Керівник:
Дата відкриття Фази 0:
```

Рівень і масштаб узяті з [[02 Наукове завдання]]; пояснення масштабів —
[[01 Конвеєр здобувача]], §2.

## Блок 2. Онтологічний якір (О-3)

**Найважливіший блок документа.** Помилка тут невидима зсередини й отруює все нижче
за течією.

```
Обʼєкт (ПРОЦЕС):
Предмет:
Мета робоча (замкнена РРРР-ММ-ДД):
```

### Три пастки

| Пастка | Хибно | Правильно |
|---|---|---|
| **Обʼєкт не як процес** | «обʼєкт — детектор аномалій» | «обʼєкт — **процес** оцінювання ефективності детекторів» |
| **Предмет = обʼєкт іншими словами** | обʼєкт «мережі FN», предмет «мережі майбутнього» | обʼєкт — процес; предмет — **те в ньому, що досліджуємо**: методика, залежність, межа |
| **Мета про світ, а не про знання** | «підвищити рівень безпеки мереж» | «**встановити**, за якої частоти зондування похибка не перевищує …» |

### Самоперевірка

```
[ ] Обʼєкт названо іменником, що позначає ПРОЦЕС (оцінювання, виявлення, керування,
    ідентифікування), а не пристрій чи мережу
[ ] Предмет НЕ можна підставити замість обʼєкта без втрати сенсу
[ ] Мета починається з дієслова пізнання: встановити / виміряти / визначити межу /
    порівняти за критерієм / спростувати
[ ] У меті є величина, яку можна порахувати
[ ] Мету датовано — це база відліку для дельти
```

> **Третя пастка найнебезпечніша.** Мета про світ робить дельту **невимірюваною**, і крок
> З-4 процедури [[07 ПЗ — Процедура закриття]] не спрацьовує ніколи: робота формально йде,
> гейт мовчить до самого захисту.

**Про два стани мети** — [[01 Конвеєр здобувача]], §4. Тут замикається **робоча**.

## Блок 3. Природа вимірів і допустимі методи

| Вимір аналізу | Природа | Допустимі методи |
|---|---|---|
| | кількісна / нормативна / змішана | |

Технічні й нормативні виміри оцінюються **окремими методами**. Зведення до єдиної шкали
без явного маркування — методологічна помилка, а не спрощення.

---

## Блок 4. Контрприпущення (О-4)

```
Центральна гіпотеза:
Рівноправна альтернатива A:
Як перевіряється:
```

**Це не критика вашої гіпотези, а інший шлях до тієї самої мети.** Без цього блоку робота
уражена телеологічним зміщенням: бажаний результат прийнято за єдину траєкторію ще до
початку аналізу.

## Блок 8. Критерій завершення

**Фіксується зараз, а не наприкінці.** Без нього робота дрейфує або «завершується»
ситуативно.

```
[ ] Усі артефакти мають статус v-final або явно відкладені з обґрунтуванням
[ ] Усі OQ-N закриті або переведені у «відкладено» з умовою повторного відкриття
[ ] MOC показує зелений статус по всіх розділах або містить явні винятки
[ ] LOG містить запис «Роботу завершено. Дата. Відкриті питання: [...]»
```

```
Мінімальний результат, за якого роботу можна подавати:
```

## Блок 9. Що НЕ входить в обсяг

```
Не досліджуємо:
Причина відсікання:
Умова повторного відкриття:
```

**Найважливіший блок після другого.** Явна межа обсягу — головний захист від розповзання
теми в оглядову компіляцію. **Порожній блок 9 означає, що тему ще не поставлено.**

Контракт розмежування з суміжними темами когорти — [[03 Паспорт напряму]].

## Блок 11. Ратифікація — КТ-0


> читання без критерію відбору.

## Що це ТЗ робить, а чого не робить

**Робить:** задає базу відліку для дельти · дає критерій відбору джерел · визначає, коли
робота завершена · фіксує межу обсягу.

**Не робить:** не описує, **як саме** ви отримаєте результат. Спосіб — предмет
[[11 A08 Дизайн дослідження]], який пишеться після Gate здійсненності.
