# 07 ПЗ — Процедура закриття

> **Що це.** Закриття питання й ухвалення рішення — **не право, а процедура**. Право підпису
> є лише її останнім кроком. Пропущений крок робить закриття недійсним, навіть якщо підпис є.

---

## Коли запускається

- закриття `OQ-N` із [[OQ — Реєстр відкритих питань]];
- ухвалення будь-якого `Р-N` для [[LOG — Журнал рішень]];
- присвоєння артефакту статусу `v2.0` або `v-final`;
- перехід між фазами ([[01 Конвеєр здобувача]], §5);
- проходження Gate здійсненності;
- позачергово — коли віха зсунулась більш ніж на 2 тижні
  ([[08 Календар віх і контрольних точок]], §6).

Для дрібних технічних дій процедура не потрібна — вони не є рішеннями.

---

## Крок З-1. Достовірність кроку

*Чи є насправді те, що заявлено?*

```
[ ] Артефакт існує у волті, а не лише в чаті
[ ] Кожне твердження марковане [E] / [Em] / [Sp] / [OP] / [VL]
[ ] Кожен ідентифікатор джерела відкритий і звірений; дата в Реєстрі джерел
[ ] Кожне число має файл-артефакт, seed, версії бібліотек, параметри
[ ] Джерела рівня 4-5 не використані як опора [E] без Р-N (к)
```

**Питання-тест:** *чи можу я зараз показати, звідки це?*
Якщо відповідь «памʼятаю» — крок недостовірний. Число з памʼяті є проксі, а не числом
([[05 META — Методологічна угода]], §6).

---

## Крок З-2. Обґрунтованість результату

*Чи висновок випливає з посилок — чи з очікування?*

```
[ ] Ланцюг «посилка -> висновок» простежується без перескоку
[ ] Ціль не підмінена проксі: виміряне справді є тим, що заявлено
[ ] Контрприпущення (О-4) розглянуте, а не згадане
[ ] Результат стійкий: повтори, інші seed, інший зріз даних
```

**Питання-тест:** *який результат змусив би мене сказати «ні»?*
Якщо такого немає — крок не обґрунтований, він **описаний**.

Підміна цілі проксі — це загроза конструктної чинності,
[[11 A08 Дизайн дослідження]], блок 8.3.

## Крок З-3. Сліпі зони — три контури й усунення

| Контур | Питання |
|---|---|
| **Повнота** | чого бракує, щоб твердження трималося? |
| **Суперечності** | що з чим не вʼяжеться — всередині артефакту й з попередніми? |
| **Сліпі зони** | чого я **не міг** побачити з цієї позиції? |

Кожна знахідка:

- **усунена** — із зазначенням, як саме;
- **зареєстрована як `OQ-N`** — обовʼязково **з умовою повторного відкриття**.

> Закрите питання без умови повторного відкриття є **хибною визначеністю**.

**Контур над контуром.** Керівник вибірково переглядає картки закриття. Підстава:
процедура, чию здатність спрацьовувати не перевіряють, створює хибну впевненість — вона
виглядає точно так само, як процедура, що працює.

---

## Крок З-4. Дельта до мети

*На скільки цей крок наблизив до мети?*

Дельта вимірюється **не обсягом зробленого, а зміною невизначеності**. База відліку —
**мета робоча** з [[04 ТЗ — Технічне завдання]], блок 2.

| Дельта | Наслідок |
|---|---|
| **позитивна** | крок закривається |
| **нульова** | крок **не закривається**; перекваліфіковується в технічну роботу без статусу результату |
| **відʼємна** — мета віддалилася, шлях виявився хибним | **це результат**; породжує `Р-N` про рескоуп |
| **невимірювана** | мета сформульована так, що дельту порахувати неможливо → повернення до `ТЗ` |

**Найчастіша причина «невимірюваної» дельти** — мета сформульована про світ, а не про
знання. Тоді гейт не спрацьовує ніколи, і робота формально йде до самого захисту
([[04 ТЗ — Технічне завдання]], блок 2, третя пастка).

## Крок З-5. Вердикт і підпис

| Вердикт | Умова |
|---|---|
| `закрито` | усі чотири кроки пройдені, дельта позитивна |
| `закрито умовно` | пройдені, лишилися `OQ-N` з умовою повторного відкриття |
| `не закрито` | із зазначенням причини й того, що треба зробити |

**Клас і підпис:** `Р-N (о)` — підписує здобувач; `Р-N (к)` — ратифікує керівник, запис
містить рядок `ратифіковано: <дата>`.

Вісім класів `(к)` — [[01 Конвеєр здобувача]], §8. Без ратифікації залежний артефакт
**не переходить у `v-final`**.

## Артефакт: Картка закриття

Один файл на кожне закриття, у теці `09 Сесії/Картки закриття/`.
**Без картки закриття не існує** — навіть якщо є підпис.

```markdown
---
created: РРРР-ММ-ДД
предмет: OQ-NN / Р-NN
клас: (о) / (к)
вердикт: закрито / закрито умовно / не закрито
---

# Картка закриття — <предмет>

## З-1 Достовірність
<чек-лист + що саме перевірено>

## З-2 Обґрунтованість
Ланцюг: <посилка -> висновок>
Контрприпущення: <як розглянуте, чому не прийняте>
Стійкість: <повтори, seed, зрізи>
Що змусило б сказати «ні»: <умова>

## З-3 Сліпі зони
| Контур | Знахідка | Статус |
|---|---|---|
| Повнота |  | усунено / OQ-NN |
| Суперечності |  | усунено / OQ-NN |
| Сліпі зони |  | усунено / OQ-NN |

## З-4 Дельта до мети
Мета робоча: <цитата з ТЗ>
Що знали до кроку: <...>
Що знаємо після: <...>
Дельта: позитивна / нульова / відʼємна / невимірювана
Обґрунтування: <...>

## З-5 Вердикт
Вердикт: <...>   Клас: (о) / (к)
Підпис: <здобувач / керівник>
ратифіковано: <дата — лише для (к)>
Умова повторного відкриття: <лише для «закрито умовно»>
```

## Два приклади

### Приклад А — закрито умовно

```
Предмет: Р-06 (о) — фіксація розбиття даних 70/15/15 зі стратифікацією
З-1: скрипт split.py у репозиторії, seed=42, контрольні суми в data/README
З-2: ланцюг — дисбаланс класів 1:340 -> без стратифікації тестова вибірка може
     не містити рідкісних класів -> стратифікація обовʼязкова.
     Контрприпущення (випадкове розбиття достатнє за великого N) перевірено:
     за 5 seed рідкісний клас відсутній у 2 випадках із 5. Відхилено емпірично.
З-3: повнота — не перевірено часову залежність -> OQ-04, умова повторного відкриття:
     при переході на потоковий протокол оцінювання
З-4: до кроку невідомо, чи вимір відтворюваний; після — відтворюваний.
     Дельта позитивна: знято загрозу внутрішньої чинності
З-5: закрито умовно (OQ-04), клас (о), підпис здобувача
```

### Приклад Б — не закрито

```
Предмет: Р-09 (к) — перехід до Фази 3
З-1: пройдено
З-2: ланцюг має перескок — з «метод X популярний в оглядах» виведено «метод X придатний
     як baseline». Популярність не є придатністю
З-3: сліпа зона — жоден із трьох оглядів не міряв на потокових даних
З-4: дельта НУЛЬОВА — обсяг зроблено великий (14 джерел), але невизначеність щодо
     baseline не зменшилася
З-5: НЕ ЗАКРИТО. Що зробити: обрати baseline за критерієм «міряний у тому ж режимі,
     що й наш вимір» ([[11 A08 Дизайн дослідження]], блок 6). Повернення до Ф2
```

> **Приклад Б важливіший за приклад А.** Він показує єдину ситуацію, де процедура справді
> працює: багато зробленого, все достовірне, а дельта нульова. Без кроку З-4 таке закриття
> пройшло б непоміченим — і виявилося б аж на захисті.
