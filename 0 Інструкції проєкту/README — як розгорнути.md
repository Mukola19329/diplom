# Як розгорнути волт — три кроки

**Напрям НД-5 — Керована деградація за інферованої критичності**

**1.** Розпакуйте архів у зручне місце **на локальному диску**.

**2.** Obsidian → **Open folder as vault** → оберіть теку
`ND-5`.

**3.** Прочитайте `! ПОЧНІТЬ ЗВІДСИ` — перший файл у корені. Він скаже, куди далі.

---

## Куди НЕ розпаковувати

Не в теку, яку синхронізує хмара — OneDrive, Google Drive, Dropbox. Усередині
волту буде репозиторій Git, а хмарна синхронізація псує репозиторії.

---

## Що всередині

| | |
|---|---|
| `! ПОЧНІТЬ ЗВІДСИ` | навігація; далі корінь працює як вхідний кошик |
| `0 Інструкції проєкту/` | 18 керуючих документів |
| `A` … `H` | робочі теки; у кожній `_ЩО СЮДИ КЛАСТИ` |
| `Z Вкладення/media/` | усі зображення, знімки, схеми, PDF |
| `.obsidian/` | налаштування: нотатки в корінь, вкладення в `Z Вкладення/media` |

---

## Якщо Obsidian не бачить теку

Переконайтеся, що обрали саме теку `ND-5`, а не ту, у якій вона лежить.
Ознака правильного відкриття: у лівій панелі вгорі видно `! ПОЧНІТЬ ЗВІДСИ`.
