# GLOSSARY

> **Живий реєстр термінів.** Правило одне: **новий термін спочатку сюди, потім у текст.**
> Термін, ужитий у роботі й відсутній тут, — дефект.
>

## Термінологічний стандарт

| Оригінал | Вживати | Не вживати |
|---|---|---|
| baseline | базова конфігурація порівняння | «бейзлайн» |
| concept drift | дрейф концепції | «концепт-дрифт» |
| ground truth | достовірна розмітка | «граунд трус» |
| trade-off | компроміс, розмін | «трейд-оф» |
| pipeline | конвеєр | «пайплайн» |
| deployment | розгортання | «деплой» |
| feature | ознака | «фіча» |
| threshold | поріг | «трешхолд» |
| overfitting | перенавчання | «оверфітинг» |
| benchmark | еталонне порівняння | «бенчмарк» |

Доповнюється по ходу. **Іншомовний термін наводиться в дужках лише при першому вживанні.**

## Розмежування, які плутають найчастіше

Заповніть для своєї теми. Формулювання «А — це не Б, бо …» рятує на захисті.

```
<термін A> ≠ <термін Б>: ...
<термін В> ≠ <термін Г>: ...
```

Приклад форми: *метод* ≠ *модель* ≠ *детектор* ≠ *методика*; *оцінка* (продукт) ≠
*оцінювання* (процес); *ефективність* ≠ *обчислювальна ефективність*.

**Особливо важливе розмежування для будь-якої теми:** *обʼєкт* ≠ *предмет*
([[04 ТЗ — Технічне завдання]], блок 2, друга пастка).

## Правило дрейфу термінології

Якщо в розділі 1 і розділі 3 те саме поняття зветься по-різному — це не стилістика, а
**ознака, що GLOSSARY не читається на початку сесії**. Виправляється не заміною слів,
а поверненням до порядку сесії.
